# 🧠 Sentiment AI

An interactive sentiment-analysis dashboard built with **Python, VADER, Pandas, Matplotlib, and Streamlit**.

### 🚀 Live Demo
**[Try the Live Demo](YOUR_STREAMLIT_URL)**

### ✨ Features
- 💬 Real-time text sentiment analysis
- 😊 Positive / 😐 Neutral / 😞 Negative classification
- 📈 Sentiment score breakdown
- 📊 CSV dataset explorer
- 🧹 Missing-value and duplicate cleaning
- 📉 Bar and percentage charts
- ⬇️ Download cleaned dataset

### 🛠️ Tech Stack
`Python` `Streamlit` `VADER` `Pandas` `Matplotlib`

